Aplicativo pessoal para computador

Organize seus cursos no Google Drive com controle e rastreabilidade.

O Organizador de Cursos - Drive é um programa local em Python que utiliza a API do Google Drive para classificar arquivos de cursos, respeitando o conteúdo programático e preservando os arquivos existentes.

Como os dados são tratadosEntenda o funcionamento

Como funciona

01

Lê o programa do curso

Interpreta o arquivo TXT mestre para identificar aulas e a sequência de conteúdos, incluindo posições sem arquivos baixados.

02

Organiza arquivos

Planeja e, após comando explícito do usuário, cria pastas, renomeia e movimenta materiais na área autorizada do Google Drive.

03

Preserva e documenta

Protege transcrições com o mesmo nome-base dos vídeos, conserva IDs dos arquivos e gera ou atualiza um manifesto Markdown do curso.

Uso local, sob controle do usuário

O programa é executado no Windows, com autenticação OAuth do Google. Não exige que o usuário envie os arquivos do curso para este site. O site existe apenas para apresentar o aplicativo, seus termos e a política de privacidade.

As permissões solicitadas no Google podem abranger todo o Drive; o programa aplica verificações próprias para limitar sua atuação à árvore de cursos ALURA. Essa limitação é feita no código, não é uma restrição imposta pelo OAuth.
