# Organizador de Cursos - Drive: páginas informativas

Este diretório contém somente o site informativo público do aplicativo pessoal **Organizador de Cursos - Drive**, no GitHub Pages.

Páginas:
- [Apresentação](https://thedrads.github.io/organizador-cursos-drive/)
- [Política de Privacidade](https://thedrads.github.io/organizador-cursos-drive/privacidade.html)
- [Termos de Uso](https://thedrads.github.io/organizador-cursos-drive/termos.html)

**Não contém código executável do organizador, conteúdos de cursos, chaves, segredos OAuth, tokens ou dados extraídos do Google Drive.**

Este diretório é independente do portfólio localizado na raiz do repositório.

A eventual publicação como aplicativo OAuth no Google Cloud exige etapas próprias de validação e não decorre automaticamente da disponibilidade destas páginas.
